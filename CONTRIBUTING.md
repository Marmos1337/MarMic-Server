# Contributing

Сейчас этот repository принимает улучшения документации и, после его публикации, открытых bootstrap-компонентов.

Перед изменением:

- не добавляйте credentials, tokens, private keys, `.env` или production data;
- не публикуйте проприетарный MarMic Server runtime или его исходный код;
- не выдавайте planned flow за уже работающую функцию;
- не добавляйте неофициальные installer-команды или непроверенные сетевые порты;
- сохраняйте модель лицензирования MarMic Server.

Публичность этого repository **не означает open-source лицензирование проприетарного MarMic Server runtime**. Contributions к документации или будущему bootstrap installer не предоставляют прав на закрытый runtime.
