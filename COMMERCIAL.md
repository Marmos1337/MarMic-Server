# Commercial Use of MarMic

MarMic Server предоставляется бесплатно для некоммерческого использования в соответствии с MarMic Server Community License.

## Что считается некоммерческим использованием

Без отдельного коммерческого соглашения разрешается бесплатно использовать MarMic Server для:

- личных серверов;
- игровых сообществ;
- серверов для друзей;
- учебных проектов;
- клубов и сообществ;
- других проектов, в которых MarMic непосредственно не используется для получения коммерческой выгоды.

Количество некоммерческих MarMic Servers не ограничивается.

## Коммерческое использование

Коммерческое использование MarMic требует отдельного соглашения с правообладателем.

К коммерческому использованию, в частности, относится:

- продажа доступа к MarMic Server;
- предоставление платного MarMic hosting;
- managed hosting на основе MarMic;
- перепродажа MarMic или его серверной инфраструктуры;
- включение MarMic в платный продукт или услугу;
- получение оплаты непосредственно за функциональность MarMic;
- предложение MarMic Server клиентам в составе коммерческого сервиса;
- white-label или аналогичное коммерческое использование.

## Индивидуальные условия

Единого публичного коммерческого тарифа пока нет.

Условия могут определяться индивидуально и включать:

- процент от выручки;
- фиксированную лицензионную плату;
- периодические платежи;
- индивидуальные условия для hosting-провайдеров;
- другие формы коммерческого соглашения.

Получение прибыли с использованием MarMic без предварительного соглашения не разрешается.

## Hosting

Вы можете бесплатно размещать собственный некоммерческий MarMic Server на своём VPS, домашнем сервере или другом оборудовании.

Предлагать установку MarMic третьим лицам как платную hosting-услугу без отдельного коммерческого соглашения нельзя.

## Модифицированные версии

Коммерческое соглашение само по себе не предоставляет право:

- получать исходный код MarMic;
- изменять официальный runtime;
- создавать собственные сборки;
- распространять модифицированные версии;
- удалять обязательные обозначения MarMic.

Такие права могут предоставляться только если они прямо указаны в отдельном соглашении.

## Как получить разрешение

Для коммерческого использования необходимо связаться с правообладателем MarMic через официальный канал связи, опубликованный в официальных ресурсах проекта.

До заключения отдельного соглашения использование регулируется MarMic Server Community License и считается разрешённым только в её некоммерческих пределах.
