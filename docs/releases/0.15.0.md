# MarMic Server 0.15.0

## Runtime

- единая immutable версия `0.15.0` в image label, `/health`, server settings и update metadata без split-brain между объявленной и запущенной версиями;
- recipient-specific realtime delivery для server mentions и replies с проверкой членства, разрешений и видимости канала;
- восстановление и reconciliation voice moderation против фактически подключённого LiveKit participant, включая move, server mute/deafen, timeout и rollback неуспешной мутации;
- общий bounded validation path для message attachments и clipboard images;
- сохранены persistent server icons, редактируемая role-based приватность text/voice channels, Registry identity и Owner state.

## Installation and updates

- stable updater проверяет versioned manifest, размер и SHA-256 до распаковки;
- config, SQLite DB/uploads, `server_id`, Ed25519 identity и Owner state сохраняются при обычном update;
- backup, lock от параллельных updates, bounded health check и automatic rollback остаются частью production path;
- bootstrap использует disk-backed `/var/tmp` staging и не распаковывает большой runtime в RAM-backed `/tmp`.
