# MarMic Server 0.14.0

## Runtime

- persistent server icon upload through the existing managed media storage, with MIME/size validation and server-side `MANAGE_SERVER` enforcement;
- editable privacy for text and voice channels through authoritative `VIEW_CHANNEL` role overrides;
- realtime channel metadata reconciliation so connected Desktop clients immediately receive privacy/name/permission changes;
- complete server mute/unmute, timeout, voice move and permission/hierarchy enforcement paths included from the consolidated 0.14.0 source;
- authenticated Registry unregister plus safe uninstall, purge and reinstall lifecycle while preserving unrelated Docker resources.

## Installation and updates

- clean install and reinstall use disk-backed staging, verify free space on the exact filesystem and remove the compressed artifact immediately after extraction;
- the bundled updater validates the stable manifest and SHA-256, takes a known-good backup, prevents concurrent updates, performs health checks and rolls back a failed activation;
- config, SQLite data/uploads, `server_id`, Ed25519 Registry identity and Owner state remain persistent across a normal update;
- release manifests are generated by the pinned bundled Node 24.13.0 runtime and no longer depend on Node being installed on the build host.
