# Домашний MarMic Server

> Статус: Planned.

MarMic Server планируется поддерживать на домашнем Linux-сервере. Для такого сценария потребуется корректная настройка маршрутизатора, port forwarding, firewall и публичной доступности.

Точный список необходимых портов и проверок будет опубликован после фиксации production network topology. Не открывайте произвольные диапазоны портов по неофициальным инструкциям.

Будущее руководство покроет:

- preflight домашней сети;
- NAT и port forwarding;
- firewall;
- динамический публичный IP и DNS update;
- HTTPS;
- проверку доступности;
- безопасный rollback сетевых изменений.
